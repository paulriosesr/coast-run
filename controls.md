# BLOOD NEON: LAST WATCH — Controls (L1 slice)

## Per player (keyboard defaults TBD in template; pad preferred)
| Action | Typical |
|--------|---------|
| Move | Left stick / WASD (P1) |
| Light attack | Face button / J |
| Heavy / smash | Face button / K |
| Dash | Shoulder / L / Shift |
| Jump / short hop | Face / Space |
| Interact / revive | Face / E (hold near downed) |

- Players 2–4: gamepads (and/or extra keyboard maps in template)

- Team finisher: automatic when 2+ hit same elite/boss in window

# COAST RUN — Controls

## Movement
| Action | Keys |
|--------|------|
| Move left | `←` or `A` |
| Move right | `→` or `D` |
| Jump | `Space` (also `↑` / `W` if easy in Phaser; **Space is required**) |

## Rules
- One jump while grounded (no double-jump in v1)
- Hold move to run; release to stop (no slide required)
- No gamepad required for v1

## UI
- No pause menu in v1
- Death → instant respawn at level start
- Flag touch → win state (freeze or simple “clear” text OK)
